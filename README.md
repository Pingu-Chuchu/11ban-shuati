# 集训复习 · 刷题

纯前端的移动端刷题应用：无框架、无构建、无后端，整个应用通过 GitHub Pages 发一个链接即可使用。

## 目录结构

```
index.html            全部应用逻辑 + 样式（单文件）
data/data.js          题库：11班集训（window.QBANK）
data/data-gt.js       题库：集团集训（window.QBANK_GT）
data/data-ag.js       题库：安规（window.QBANK_AG，由 Excel 导入生成）
lib/qbank-core.js     Excel → 题库 的共享转换核心（网页与命令行共用）
lib/xlsx.full.min.js  SheetJS 0.18.5（网页内解析 Excel 用，按需懒加载）
tools/build-bank.js   命令行转换工具（Node）
```

## 功能要点

- 多题库：底部卡片切换，各库做题记录 / 错题本 / 收藏相互隔离，支持 `#ag` 这类 hash 直达。
- 题型：单选、多选（全对才判对）、判断、**简答**（查看参考答案 → 自评对/错，计入统计与错题本）。
- **保命题**：题目带 🛡 标记，组卷中心与题库列表可勾选「仅保命题」筛选。
- 组卷：按课程 / 题型筛选，顺序或随机抽题；错题专练答对自动移出错题本。
- 学习记录存 localStorage，支持导出 / 导入 JSON 备份；深色模式；离线可用。

## 题库数据格式

`data/data-*.js` 中每道题为紧凑字段（JSON）：

| 字段 | 含义 | 说明 |
|------|------|------|
| `i` | 题目 id | 数字，库内唯一 |
| `c` | 课程索引 | 指向 `courses` 数组下标 |
| `t` | 题型 | 1 单选 / 2 多选 / 3 判断 / 4 简答 |
| `s` | 题干 | |
| `o` | 选项数组 | 单选/多选必填，判断与简答不填 |
| `a` | 答案 | 单选 `"A"`；多选 `"ABD"`（字母升序）；判断 `"对"/"错"`；简答为参考答案全文 |
| `e` | 解析 | 导入时取 Excel 的「出自规范」列 |
| `n` | 备注 | 可选 |
| `r` | 真题标记 | `1` 显示红色「真题」徽章 |
| `p` | 保命题标记 | `1` 显示 🛡 徽章并可筛选 |

## 如何更新 / 新增题库

### 方式一：网页内导入（推荐）

打开应用 → 设置 → 「📥 导入 Excel 题库」→ 选择 Excel 文件 → 查看解析报告（题量统计、警告、被跳过的行）→ 二选一：

1. **生成题库文件**：下载 `data-<id>.js`，放进 `data/` 目录，并在 `index.html` 里加一行
   `<script src="data/data-<id>.js"></script>`（放在其它 data 脚本之后）。
   生成文件会自注册到 `window.QBANK_EXTRA`，刷新后自动出现在题库列表，无需改其它代码。
2. **存为本地题库**：只存在当前设备的 localStorage 中，不进仓库（设置页可删除）。

### 方式二：命令行转换

```bash
node tools/build-bank.js <Excel文件> <输出.js> <短id> <题库名称>
# 例：node tools/build-bank.js "题库（2026年版）.xlsx" data/data-ag.js ag 安规
```

同时在输出旁生成 `.report.txt` 解析报告（读了几行、收了几个、跳过原因）。

### Excel 格式约定

- 按题型分 Sheet（单选题 / 多选题 / 判断题 / 简答题），表头行任意位置均可，自动识别。
- 列：`序号`（忽略，自动按行序重排 id）、`题型`、`难易度`（忽略）、`知识类别`、`题干`、
  `A`~`I`（选项列，可有可空）、`正确答案`、`出自规范`、`是否保命题`、`修编情况`（忽略）。
- 答案自动归一化：多选 `A、B、D` / `ABD` 等写法均可；判断题支持字母（A=正确 / B=错误，
  见选项列）、对/错/正确/错误/√/× 等；「是否保命题」填 是/√/Y 即标记。
- 有问题的行不会中断导入：会在报告中列出被跳过的行及原因，其余题正常入库。
